# Navio Server

> 跑在 Windows 宿主机上的 Web 书签导航服务。桌面端只显示服务端控制台，书签页面通过浏览器或手机远程访问。

所有数据写在宿主机的 JSON 文件里，没有 MySQL、没有 Docker、不依赖外部服务。桌面程序负责托管服务与管理配置，Web 端提供完整的起始页体验。

---

## 功能特性

- **远程书签导航** —— 桌面程序在 9200 端口启动 HTTP(S) 服务，本机 `http://127.0.0.1:9200`、局域网 `http://<宿主机IP>:9200` 均可访问，手机与外网（端口转发 / 内网穿透）同样可用。
- **管理面隔离** —— Electron 桌面窗口只显示「服务端控制台」（端口、账号、数据、安全、日志）；管理操作只走本地 IPC，HTTP 端口上不存在管理接口，公网无法改端口或账号。
- **公共模板 + 个人快照** —— 公共书签作为只读模板，任何人的增删改只写自己的 `spaces[身份ID]` 快照，不影响他人；登录后可用匿名快照自动继承。游客也能用起始页，匿名身份用 HttpOnly Cookie 标识。
- **多搜索引搫** —— 大搜索框支持百度、谷歌、必应、360、搜狗、DuckDuckGo、GitHub 七个引擎切换，回车联网搜索，输入网址则直接打开；切换结果写入个人设置。
- **左侧分类栏** —— 公共分类与个人标签合并为一个连续列表，支持自定义分类图标；单个书签可设 `1x1 / 2x1 / 1x2 / 2x2` 占格与自定义背景色，CSS Grid dense 布局。
- **真实站点图标** —— 内置常用站点官方 favicon，离线可用；未收录域名在线抓取 → 内置自绘 SVG → 渐变首字母多级降级，不会出现清一色字母块。
- **桌面组件** —— 待办、日历、天气、记事本四个可开关组件；天气经服务端代理查询 Open-Meteo（无需 Key），离线时可手动填写。组件数据与书签同存一个 JSON 文件。
- **多级主题** —— 深 / 浅两套主题、毛玻璃与光晕效果，窄屏自适应。
- **服务端控制台** —— 概览（状态 / 监听地址 / 在线会话 / 访问地址）、服务与端口（含开机自启、HTTPS 证书、防火墙放行命令）、访问安全（登录开关、会话时长、失败锁定、IP 白名单、反代设置）、账号密码、数据备份 / 恢复 / 导入导出、内置图标库、运行日志。
- **常驻与托盘** —— 关闭控制台窗口隐藏到系统托盘，Web 服务继续运行；托盘菜单可打开控制台、设置、浏览器、重启服务、退出；开机自启写入当前用户启动项。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Node.js 原生模块（无第三方运行时依赖），HTTP(S) 路由与鉴权 |
| 桌面 | Electron 主进程，控制台通过 `loadFile` 本地加载 |
| 前端 | 原生 JS / CSS，浏览器端通过 `navio-http.js` 实现与 Electron preload 相同的 `window.navio` 接口，一套 UI 两端通用 |
| 存储 | JSON 文件落盘，原子写 + 滚动备份，无数据库 |

数据目录内容：`data.json`（书签 / 分组 / 组件 / 用户空间）、`users.json`（scrypt 加盐哈希）、`sessions.json`、`server.json`（端口 / 安全配置）、`backups/`、`favicons/`。

## 快速开始

**开发态**：在项目根目录运行 `node_modules/.bin/electron .`（或 `npm start`）。

**打包态**：运行打包脚本生成免安装目录版，双击 `Navio.exe` → 弹出服务端控制台 → 服务自动在 9200 端口启动 → 点「在浏览器中打开」或访问 `http://127.0.0.1:9200`。

**首次登录**：首次启动生成随机管理员密码，写入数据目录的 `INITIAL_ADMIN.txt`，控制台「账号密码」页也会显示。登录后请立即修改密码并删除该文件。

远程访问：

| 场景 | 做法 |
|---|---|
| 本机 | `http://127.0.0.1:9200` |
| 局域网 | `http://<宿主机局域网IP>:9200` |
| 公网 | 端口转发 / 内网穿透，务必修改初始密码并启用 HTTPS 与 IP 白名单 |
| 反向代理 | 反代到 9200，并在「访问安全」开启「信任 X-Forwarded-For」 |

端口、绑定地址、HTTPS、开机自启都在控制台修改，改完点「保存并重启服务」。

## 安全设计

| 项 | 实现 |
|---|---|
| 密码 | scrypt(N=16384, r=8, p=1) + 16 字节随机盐，时序安全比较 |
| 会话 | 32 字节随机 token，HttpOnly Cookie，默认 7 天，持久化到 `sessions.json` |
| 登录限流 | 按 `IP|用户名` 计数，连续 5 次失败锁定 15 分钟 |
| 请求限流 | 每 IP 每分钟 600 次；支持 IP 白名单与网段前缀 |
| 响应头 | `X-Content-Type-Options`、`X-Frame-Options: DENY`、`Referrer-Policy`、CSP |
| 管理面隔离 | 账号 / 端口 / 重启 / 清空数据只走本地 IPC，HTTP 上返回 404 |
| 路径穿越 | 静态文件 `safeJoin` 校验，上传文件名做白名单处理 |
| HTTPS | 可配置 cert / key 路径，或由反向代理终结 TLS |
| 多用户隔离 | 每个账号独立书签空间，互不可见 |
| 导出边界 | 导出只含当前身份视图，恢复仅管理员可用 |

## 项目结构

```
electron/        主进程与控制台（窗口 / 托盘 / 设置 IPC）
renderer/        Web 页面：首页、书签 UI、组件、主题、图标
src/             服务端：路由、鉴权、空间隔离、配置
tools/           图标抓取、分组合并、打包辅助脚本
console.html     桌面控制台页面（仅本地加载）
```

主要脚本：`npm start` 启动桌面端，`npm test` 运行核心测试，`npm run dist` 打包便携版。

---

## 已知限制

- 桌面控制台只在 Electron 本地窗口可用，Web 端没有管理界面（这是设计取舍）。
- 公网访问的安全性依赖用户自己配置 HTTPS 与访问控制，默认明文 HTTP。
- 数据集中在单个 `data.json`，超大书签量下读写性能会下降，建议定期备份。
